# Verify Crystal Ball

## Launch
Run from this checkout. `npm install`, then `npm run server` (127.0.0.1:8787) and `npx expo start --web --no-dev --minify --port 8087` (localhost:8087, no dev overlay). Keep each command's PID/session for teardown. Ollama must already serve the local Qwen model at 127.0.0.1:11435; SETUP.md documents isolated model storage. Do not stop another checkout's servers. Native simulator verification remains deferred by firstmate because Xcode is absent.

## Doctor
`curl -fsS http://127.0.0.1:8787/health` must identify crystal-ball and ollama. `npm run check` must pass. Confirm Expo log says localhost:8087. Use `CHROME_DEVTOOLS_AXI_SESSION=crystal-ball chrome-devtools-axi open http://localhost:8087 --full` and `emulate --viewport "390x844x1,mobile,touch"`. Use the named session only. Never drive an unrelated profile.

## Drive
Use `node scripts/drive.mjs` then `node scripts/drive-extended.mjs`, then `node scripts/drive-states.mjs` and `node scripts/drive-general.mjs` for the primary observed-control drive. These launch an isolated temporary Chrome context against localhost, use stable data-testid controls, and close that context even on failure. Firstmate explicitly authorized Playwright and DOM eval after chrome-devtools-axi generation references repeatedly failed. For ad hoc work, use chrome-devtools-axi eval against localhost; snapshot IDs are currently unreliable. `snapshot --full`, `click @<observed-id>`, `fill @<observed-id> 'text'`, `scroll down`, and `screenshot <absolute-evidence-path> --format jpeg` are the basic recipe. Stable test IDs include tab-home, tab-explore, tab-ask, tab-history, tab-you, question-input, option-0 through option-3, answer-next, other-input, why-disclosure, view-plans, and export-animated-story. Stable accessible names: Home, Explore, Ask the crystal ball, History, You, Your question, Look into the future, Your own answer, Next, Reveal my prediction, Why this prediction?, Share this glimpse, Export story card, View plans, Reduce motion.

Start Home -> Ask -> choose Spanish suggestion -> Look into the future. Select one radio option per card, confirming Next. Use Other once with a typed answer. Wait for the real local model reveal. Expand Why; confirm the stated timeframe is preserved, the headline fits, the speculative label remains visible, and actual sources or no-source state appears. Open History, reload, reopen the same prediction. Open You, edit and forget a fact, start again and verify remembered values are skipped. Ask a sensitive question and confirm the kind redirect, unchanged credit count and no new history. Open share, inject the documented HTTP-500 export failure and assert the error notice is in the viewport; export the actual PNG; inspect 1080×1920 dimensions and absence of private facts. Open View plans; confirm test-mode disclosure, simulate a pack and observe credit count, test Restore. Explore friend link must include friend=1; its answers cannot enter You. Finish at375×667 and 200% app text, with reduced motion enabled and all five tab labels visible.

Stop only server/Expo processes started for this drive, using their captured sessions/PIDs. Keep docs/evidence. Use You -> Reset local data only in this isolated test profile, after recording needed side effects. No public posting or real payments. Do not kill by process name. If leaving the app up for review, record the two owned process sessions and pending cleanup rather than claiming cleanup happened.

Browser interactions are intentionally through observed accessible controls, not test-only APIs.
