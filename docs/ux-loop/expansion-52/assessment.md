# Parchment edge repetition study (prepared during round51 verification)

Both round50 graders capped nearly every surface at 8, citing identical parchment borders ("stamped-image appearance", "reduce the visual weight of identical parchment borders"). Every Paper/PaperButton uses the same nine-slice (paper.webp, 14px/18px) and the same clip polygon.

Candidate for round52 if round51 grades still cap surfaces at 8. Static concept only; no production proof.
