Current typography is IM Fell English SC and Caudex, with the protected IM Fell English Italic wordmark; see [selected font provenance](SELECTED.md).

The retained IM Fell English (regular and italic) and Hanken Grotesk files match the original supplied Crystal Ball design. Latin WOFF2 files were extracted from that export. Native TTF files and their OFL licenses come from the corresponding `ofl/imfellenglish` and `ofl/hankengrotesk` directories in [google/fonts](https://github.com/google/fonts). No runtime font network requests are required.
