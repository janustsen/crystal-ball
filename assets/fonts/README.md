Runtime typography follows the [UI rules](../../docs/design/ui-rules.md#palette-and-composition): IM Fell English (regular and italic) for headings, Cormorant Garamond (regular and SemiBold) and Jost (regular and Medium). Their Latin WOFF2 and static TTF files are the ones Google Fonts serves for the Sky & History artboards' `css2` request; Jost ships as static TTFs on every platform because its WOFF2 is a single variable file. OFL licenses come from `ofl/cormorantgaramond` and `ofl/jost` in google/fonts. Other bundled faces remain for scripts and generated design CSS that still name them.

IM Fell English (regular and italic) and Hanken Grotesk come from the earlier Crystal Ball design. Latin WOFF2 files were extracted from that export. Native TTF files and their OFL licenses come from the corresponding `ofl/imfellenglish` and `ofl/hankengrotesk` directories in [google/fonts](https://github.com/google/fonts). No runtime font network requests are required.

The source Claude Design canvas Library artboard uses Cormorant Garamond 500 (regular and italic) and Instrument Sans 500 from Google Fonts. Their Latin WOFF2 and static TTF files are the ones Google Fonts serves for that artboard's `css2` request; OFL licenses come from `ofl/cormorantgaramond` and `ofl/instrumentsans` in google/fonts.
