# Font choice · static Open mist compositions

Preview: http://janus-mac.tail8d2280.ts.net:8098/concepts/fonts.html

- A — Cormorant Garamond + DM Sans: lunar/editorial, delicate display detail.
- B — Fraunces + Manrope: warm illustrated character; recommended for the existing ball art, but friendlier than A.
- C — Lora + Source Sans 3: restrained storytelling and clear reading, less distinctive.

Each pairing appears on Home, reading reveal, History and Plans at 390×844, normal and 200% text. Same words and composition across alternatives. Static typography prototypes, not functioning product flows or final animation. Plans contain explicitly illustrative prices. Both fonts in each pair are served locally; no third-party font request during viewing.

Fonts and OFL licenses downloaded from the upstream Google Fonts repository's `ofl/cormorantgaramond`, `ofl/dmsans`, `ofl/fraunces`, `ofl/manrope`, `ofl/lora`, `ofl/sourcesans3` directories at https://github.com/google/fonts/tree/main/ofl . Original license files accompany each font under public/concepts/font-assets.

Validation: 24 phone compositions, actual loaded-font checks, zero page errors and no document horizontal overflow. Direction switcher, enlarged-text toggle and screen jump exercised in isolated Chromium. Full production layout/flow verification follows the captain's choice; these observations do not certify native Dynamic Type.
