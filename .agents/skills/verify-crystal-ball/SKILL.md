# Verify Crystal Ball

## Launch
Run from this checkout. `npm install`, then `npm run server` (127.0.0.1:8787) and `npm run web -- --no-dev --minify --host lan --port 8087` (localhost:8087, no dev overlay). Keep each command's PID/session for teardown. Concurrent worktrees must use separate ports and a checkout-local `TMPDIR` (for example `.local/tmp`) for Expo, because shared Metro transforms can reuse another lane’s public environment variables. The server accepts `PORT`/`APP_ORIGIN`; use the same `ENGINE_PORT` for Expo’s bridge. Current drivers accept `PREVIEW_URL`, and the launch driver accepts `APP_URL`. Ollama must already serve the local Qwen model at 127.0.0.1:11435; SETUP.md documents isolated model storage. Do not stop another checkout's servers. Native simulator verification remains deferred by firstmate because Xcode is absent. Supabase is optional. Native checks require Xcode and a development build; do not claim browser checks as native proof.

## Motion audit
After the functional drives finish, run `node scripts/drive-motion.mjs` on its own. It uses a fresh named chrome-devtools-axi profile, captures perf-start/perf-stop traces at 390×844, counts actual WebGL draws and display frames through each interaction, and closes only its own browser. Do not run other browser drives or bundle builds concurrently with the timing sample. The trace covers idle hero/Ask fog, approach, listening, typing, the returned one or two questions, thinking/reveal, sharing, tabs and 45 seconds of ambient sky. Targets: >=58fps, p95 <=20ms, no sampled frame >50ms and no long main-thread tasks. Keep failed measurements with their cause; do not replace them with an unexplained pass.

Inspect the image and watch both spheres: fog must deform without a rotating plate, reset or reverse; wisps escape and dissipate under a warm glow. Confirm sky visitors are above the room but behind the ball. Run `node scripts/check-motion-accessibility.mjs`. Toggle Reduce motion and confirm the canvas stops drawing and CSS animations stop; repeat with the OS preference and verify both orbs remain visible at large text. Native `Animated` uses its native driver, but an iOS bundle is not evidence of device frame rate. If no simulator/device is available, report that remaining boundary explicitly.
