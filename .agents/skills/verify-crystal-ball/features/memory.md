# Memory

## Sub-features
Edit/delete known facts; persisted history; yes/no/pending check-back and local reminder.

## How to get to it (user POV)
You for facts; History for earlier readings.

## Driving it with chrome-devtools-axi
Edit a fact, reload, verify value; forget it, ask again and verify it returns as a card. Open history and mark an outcome.

## Gotchas
Friends never teach the owner bank. Web reminder is an explicit preview, not a scheduled native notification.
