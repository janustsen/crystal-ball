I scored the app phase **6.4/10**, below the 9 bar. The core flow does work: real local Qwen, about 1.8 s per prediction, persistence, safety redirects and offline retry are all observed. Four problems keep it from 9:

1. **Canned predictions.** For every topic the drive tests, the server chooses the answer with if-then rules, and the model just echoes it.
2. **Stale evidence.** The recorded evidence predates the current engine code.
3. **Blank empty screens.** The empty History and You screenshots show nothing.
4. **Frame rate.** Animation runs at about 13 frames per second.

I only read files; I did not modify anything or run the app. The 13 fps figure comes from headless Chrome and isn't a native measurement.
