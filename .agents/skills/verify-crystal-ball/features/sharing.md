# Sharing

## Sub-features
Explore seeded prompts; friend link; private 9:16 export.

## How to get to it (user POV)
Explore, or Share this glimpse on a reveal.

## Driving it with chrome-devtools-axi
Open a sample prompt, create friend link, inspect friend mode. Export story card and inspect downloaded file dimensions and contents. Export the MP4 too. The primary driver injects HTTP 500 for one export and verifies recoverable error copy; that is a fault-injection check, not a claimed live outage.

## Gotchas
Seeded feed is labeled. Browser sharing may be canceled. No automatic external posting.
