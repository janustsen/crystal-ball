# Hosted readings

Public readings use the Supabase predict function and `server/hosted-limits.ts`. It verifies the caller through Supabase Auth before any inference, then uses service-only SQL admission and money RPCs. It pins Cloudflare Llama first and DeepInfra Qwen backup, requires `cloudflare-deepinfra-v1` consent, provider-specific credentials and independent `CLOUDFLARE_QUALITY_APPROVED` / `DEEPINFRA_QUALITY_APPROVED` flags. Free neurons use a separate atomic UTC-day ledger; every paid attempt retains the $25/month money boundary. Local Node development still uses Ollama by default. The aggregate `heard` attribution action uses no identity or model.

## Repeatable checks without paid inference

1. Run `npm run check` and `npm test`, including `tests/hosted-limits.test.ts` and `tests/hosted-first-card.test.ts`. The former drives the public handler and shared provider: missing/expired auth, unapproved quality, wrong vendor, quota and budget denial, repair ordering, retained failure/missing-usage reservations. The latter drives real engine planning with fast/slow fake providers and a simulated clock: first-card p50/p95, the inclusive 10-second limit, repair/validation time, failed plans, missing samples and sensitive redirects. Run `npx tsx scripts/hosted-bakeoff.ts --check` for the offline spending-boundary checks. These tests make no live provider calls and establish neither vendor latency nor semantic quality.
2. With PostgreSQL 17 available, set `TMPDIR` to an owned scratch directory and run `python3 scripts/verify-hosted-limits.py`. It creates and tears down its own loopback database on `HOSTED_PG_PORT` (default 55478), applies the real migrations and proves starter/free/Plus/pack allowances, shared reading attempts, ancillary quotas, concurrent daily and monthly admission, the exact $25 cap, idempotent settlement, UTC rollover and client denial of service-only RPCs. It proves SQL behavior, not hosted Supabase Auth/PostgREST compatibility.
3. Launch the standard isolated Node/Expo preview with `EXPO_PUBLIC_AI_PROVIDER_NAME="Cloudflare and DeepInfra"` in Expo only; leave Node's model local. Doctor its authenticated `/engine/health`. Run `APP_URL=<preview-url> CHECK_AI_CONSENT=1 EVIDENCE_DIR=<owned-scratch> node scripts/drive-launch.mjs` for consent enable/revoke and settings readability.
4. Run `APP_URL=<preview-url> EVIDENCE_DIR=<fresh-owned-scratch> node scripts/drive-hosted-limits.mjs`. It checks the Cloudflare/DeepInfra details and denied-until-consented Ask, then injects two explicitly labeled 429 planning replies. Inspect the saved consent, monthly and daily screenshots: their text must be readable. Reduced motion makes capture deterministic. No vendor is called; do not label these UI faults as a live provider or database test. A cold Metro bundle can outlive navigation's timeout; retain the failure, doctor, warm the bundle and retry.

## Required before public activation

Follow `docs/launch/hosted-model.md`. The authorized benchmark is Workers Free Cloudflare and DeepInfra under $1, versus today's local Qwen. Each provider requires its own semantic/safety review and a passing `firstCardGates` result (complete planning samples and nearest-rank first-card p95 <= 10 seconds); both flags default false. Inspect per-case `firstCardSeconds` and the reported p50/p95 separately from whole-reading duration. Missing provider keys in the designated external key file skip that provider with an unpassed latency gate; no paid call is possible without its key. Preserve failures and inspect semantic forecasts/cards and sensitive redirects before setting quality approval. Never claim valid JSON or fake-provider latency establishes semantic quality, real vendor latency or predictive accuracy.

After credentials and an approved Supabase target exist, deploy and smoke the actual hosted URL with an anonymous session: no/expired bearer and missing/wrong AI consent refuse before paid inference; a valid request returns a real reading; exhausted quotas and budget return the readable messages with no outbound model request. Inspect the server ledger and vendor usage. Local checks do not substitute for this hosted smoke or native TestFlight verification.
