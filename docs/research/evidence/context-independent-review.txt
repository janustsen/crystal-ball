# Crystal Ball context-bound pilot: independent review

**Score: 4.5 / 10.** On their own the 21 rows are clean. But the pilot mostly tests fixtures written by hand in `scripts/research-boundaries.py`. It does not test the choices the shipped engine builds (`server/engine.ts:17-34`). When I check the real engine path, the grounding breaks in several places. This is a structural and semantic review only. It says nothing about whether any forecast is accurate.

## What the model actually did vs. what the server did

- **21 rows = 7 fixtures × 3 attempts.** Each fixture gave the same output on all 3 attempts, so there are really 7 data points, not 21.
- **In 3 of the 7 fixtures the model did no creative work.** Growth had one allowed answer, and "Who wins the World Cup?" had one clarify token. The model can only return that single string.
- **In the other 4 the model picked between two sentences the server wrote.** Correct names, places and numbers come from the fixtures, not from the model. So "grounding 10/10" is true by construction and says nothing about the model's grounding ability.

## Concrete blockers

1. **The pilot doesn't match the shipped engine.** Relocation, learning, sports and the clarify case all use different choice sentences from `engine.ts`. The EV case doesn't exist in the engine at all. The pilot needs to run through `predict()` before the "21 picks fit" claim in `decisions.md:8` can stand.
2. **Any learning question becomes Spanish.** `questions.ts:13` sends anything matching `spanish|learn|fluent|language` to the learning template, which asks for "your Spanish level" and always returns a Spanish headline. So "Will I learn Danish?" or "Will I learn to code?" gets a forecast about Spanish. The deadline card is collected and then ignored in the headline.
3. **Sports can produce events that don't exist.** The cards allow Men's World Cup 2027 or 2034 and NBA 2030 or 2034. The team options are Argentina, Spain and USA, with no Lakers. The template then renders "Spain will win the 2027 Men's World Cup." (that tournament doesn't exist) or "Lakers will miss the 2027 NBA championship title." (clumsy wording).
4. **The clarify case is an unfinished fixture, not a working feature.** A sentinel string must never be shown as a headline, and a clarify screen must not be labelled as a forecast.
5. **Zero variance across attempts.** The model always picks the same option, so the "specific, surprising" reveal becomes a fixed coin that always lands the same way. That trade-off is still undecided (the round‑4 grades flagged it too).
6. **General questions with no template are ungraded.** This is where the model's creativity and the real grounding risk actually sit.
