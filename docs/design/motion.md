# Motion

The [motion language](motion-language.md) defines the shared primitives, reference lessons, easing and timings. `src/motion.ts` owns screen entrance tokens; `src/Enter.web.tsx` uses compositor transforms/opacity, while `src/Enter.tsx` uses React Native’s native animation driver.

`src/fogShader.ts` adapts the supplied reference into continuously advected domain-warped fog, without rotating the field. Outside the [room](#room), one persistent WebGL context draws the shared orbs, including escaping wisps. While visible with motion enabled, it runs at display cadence and keeps its clock across state changes. Glow, embers and sky discoveries animate only transforms/opacity. Native `FogTiles` moves three seamless translucent fields with the native driver beneath transparent glass artwork; native wisps recycle only at zero opacity. Run `node scripts/render-fog.mjs` to regenerate those assets. No frame-sequence assets or per-frame React updates are used.

Reduced motion freezes the fog, removes entrances and hides sky visitors. Either the system preference or in-app setting skips the approach delay. Large text caps shared decorative orbs at 96 pt; The room keeps its composition and its screens scroll the scaled text. The web fog stops scheduling animation callbacks while reduced motion is active, apart from one-off redraws for layout or content changes that apply the current mood immediately. Hiding the page cancels its pending callback; restoring visibility or disabling reduced motion resumes it without advancing through the paused interval. It cleans up on unmount. WebGL-unavailable browsers retain the still glass artwork. Native device frame-rate evidence is separate from compilation and browser proof.

## Room

Every tab is a spot in the approved AI-rendered library room (`src/RoomScene.web.tsx`, assets from `scripts/room-assets.mjs`): Home is the wide room with the ball on the desk, Sky the round skylight, Ask the ball close-up, History the scroll shelves, You the armchair and side table. A tab change plays the direct 1.5 s flight clip from the current spot, then the destination's seamless 5 s loop; each flight starts and ends on its spots' stills, so still → flight → loop cuts without crossfades. A change during a flight, or before the clip is cached, cuts straight to the destination still. Home's still and loop and every spot still ship in the bundle; flights and the other loops stream from `EXPO_PUBLIC_ROOM_ASSET_BASE` and are prefetched after launch (Cache API where the origin allows it, else the HTTP cache), then played from memory.

The canvas Library glass ball is drawn live over the video in its own transparent canvas: each frame's tracked ball position, radius, view direction, depth-of-field blur and candle flicker (`src/roomTrack.json`) place and light it on the render's brass ring. Its procedural library room is kept only to light and reflect in the glass, captured once. Drag-to-spin with momentum works at Home and Ask; a tap without a drag starts a reading at Home and asks a ready question at Ask. Reduced motion plays no flights or loops, fades between stills (Web Animations, since the shell's reduced-motion rule stops CSS animations) and draws the ball one frame at a time; drag moves still redraw it. Hidden pages cancel pending callbacks. Without WebGL the static orb sits in the ring. Native shows the stills (cut, or fade for reduced motion) with the static orb; follow-up `cb-native-room-video` owns expo-video flights cached with expo-file-system, and needs a device build.

## Orb delight

Gold editions add a rim/halo using the existing reveal entrance and retain the speculative label. Static Plus skins tint the existing glass; they do not change the fog renderer.

Native orb touches use a soft impact; thinking pulses every half glow cycle; a newly completed reveal uses a heavy impact. Ambient hum and reveal chime are optional, default off, pause during voice capture/backgrounding, and native playback respects the silent switch. Browser autoplay rejection is handled and a later deliberate tap can resume the enabled hum. Native haptic feel and silent-switch behavior still require device verification.
